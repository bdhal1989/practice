📘 COMPOSITE PATTERN - COMPLETE NOTES
=================================================

CATEGORY

Structural Design Pattern

=================================================
DEFINITION
=================================================

Composite Pattern is a Structural Design Pattern
that allows individual objects and groups of
objects to be treated in the same way.

Simple Rule:

Composite = Tree Structure

Examples:

✔ Company Hierarchy
✔ Folder Structure
✔ Menu System
✔ HTML DOM
✔ Organization Chart

=================================================
WHY DO WE NEED IT?
=================================================

Suppose we have:

CEO
 |
 +---- Manager
         |
         +---- Developer

We want to call:

showDetails()

on:

✔ Developer

and

✔ Manager

using the same interface.

Composite Pattern allows us to treat
both individual objects and groups
of objects uniformly.

=================================================
COMPONENTS OF COMPOSITE PATTERN
=================================================

1. Component

Common interface shared by all objects.

---------------------------------

2. Leaf

Individual object.

Cannot contain children.

---------------------------------

3. Composite

Group object.

Can contain children.

---------------------------------

Structure

Component
    |
 -------------------
 |                 |
Leaf         Composite

JAVA IMPLEMENTATION
-------------------------------------------------

interface Employee {

    void showDetails();
}

-------------------------------------------------

class Developer
implements Employee {

    private String name;

    public Developer(String name) {

        this.name = name;
    }

    @Override
    public void showDetails() {

        System.out.println(
                "Developer : " + name);
    }
}

-------------------------------------------------

class Manager
implements Employee {

    private String name;

    private List<Employee>
            employees =
            new ArrayList<>();

    public Manager(String name) {

        this.name = name;
    }

    public void addEmployee(
            Employee employee) {

        employees.add(employee);
    }

    @Override
    public void showDetails() {

        System.out.println(
                "Manager : " + name);

        for(Employee employee :
                employees) {

            employee.showDetails();
        }
    }
}

-------------------------------------------------

USAGE

Manager manager =
        new Manager("Suyash");

manager.addEmployee(
        new Developer("Amit"));

manager.addEmployee(
        new Developer("Rahul"));

manager.showDetails();

EXAMPLE 5 - HTML DOM TREE
=================================================

SCENARIO

<html>
  <body>
      <div>
          <p>Hello</p>
      </div>
  </body>
</html>

-------------------------------------------------
IMPLEMENTATION MAPPING
-------------------------------------------------

Component

HtmlElement

Leaf

TextNode

Composite

ContainerElement

-------------------------------------------------
JAVA IMPLEMENTATION
-------------------------------------------------

interface HtmlElement {

    void render();
}

-------------------------------------------------

class TextNode
implements HtmlElement {

    private String text;

    public TextNode(String text) {

        this.text = text;
    }

    @Override
    public void render() {

        System.out.println(text);
    }
}

-------------------------------------------------

class ContainerElement
implements HtmlElement {

    private String tag;

    private List<HtmlElement>
            children =
            new ArrayList<>();

    public ContainerElement(
            String tag) {

        this.tag = tag;
    }

    public void add(
            HtmlElement element) {

        children.add(element);
    }

    @Override
    public void render() {

        System.out.println(
                "<" + tag + ">");

        for(HtmlElement element :
                children) {

            element.render();
        }

        System.out.println(
                "</" + tag + ">");
    }
}

=================================================
COMMON TEMPLATE
=================================================

interface Component {

    void operation();
}

-------------------------------------------------

class Leaf
implements Component {

    @Override
    public void operation() {

        System.out.println(
                "Leaf");
    }
}

-------------------------------------------------

class Composite
implements Component {

    private List<Component>
            children =
            new ArrayList<>();

    public void add(
            Component component) {

        children.add(component);
    }

    @Override
    public void operation() {

        for(Component component :
                children) {

            component.operation();
        }
    }
}

✔ Uniform Treatment

=================================================

❌ Difficult To Restrict Tree Structure

✔ Parent Child Relationship Exists

✔ Individual And Group Objects
  Must Be Treated Uniformly
