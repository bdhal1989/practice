=================================================
📘 PROXY PATTERN - COMPLETE NOTES
=================================================

CATEGORY

Structural Design Pattern

=================================================
DEFINITION
=================================================

Proxy Pattern is a Structural Design Pattern
that provides a substitute or placeholder
for another object to control access to it.

Simple Rule:

Proxy = Control Access

OR

Proxy = Middleman

=================================================
WHY DO WE NEED IT?
=================================================

Sometimes direct access to an object is
not desirable.

Reasons:

✔ Security

✔ Lazy Loading

✔ Access Control

✔ Logging

✔ Caching

✔ Remote Access

-------------------------------------------------

Example:

User
  |
  v
Bank Account

Direct access may be dangerous.

Instead:

User
  |
  v
Proxy
  |
  v
Bank Account

=================================================
CORE IDEA
=================================================

Client talks to Proxy.

Proxy decides:

✔ Allow Access

✔ Deny Access

✔ Cache Data

✔ Load Object Lazily

✔ Log Requests

Then forwards request to Real Object.

=================================================

EXAMPLE 1 - BANK ACCOUNT SECURITY
=================================================

SCENARIO

Only authorized users should access
their bank account.

-------------------------------------------------
IMPLEMENTATION MAPPING
-------------------------------------------------

Subject

BankAccount

---------------------------------

Real Subject

RealBankAccount

---------------------------------

Proxy

BankAccountProxy

-------------------------------------------------
JAVA IMPLEMENTATION
-------------------------------------------------

interface BankAccount {

    void withdraw(
            double amount);
}

-------------------------------------------------

class RealBankAccount
implements BankAccount {

    @Override
    public void withdraw(
            double amount) {

        System.out.println(
            "Withdrawn : " + amount);
    }
}

-------------------------------------------------

class BankAccountProxy
implements BankAccount {

    private RealBankAccount account =
            new RealBankAccount();

    private boolean authorized;

    public BankAccountProxy(
            boolean authorized) {

        this.authorized = authorized;
    }

    @Override
    public void withdraw(
            double amount) {

        if(authorized) {

            account.withdraw(amount);

        } else {

            System.out.println(
                "Access Denied");
        }
    }
}

-------------------------------------------------

USAGE

BankAccount account =
    new BankAccountProxy(true);

account.withdraw(1000);

EXAMPLE 2 - IMAGE LAZY LOADING

SCENARIO

Large image should load only when
required.

-------------------------------------------------
IMPLEMENTATION MAPPING
-------------------------------------------------

Subject

Image

---------------------------------

Real Subject

RealImage

---------------------------------

Proxy

ImageProxy

-------------------------------------------------
JAVA IMPLEMENTATION
-------------------------------------------------

interface Image {

    void display();
}

-------------------------------------------------

class RealImage
implements Image {

    public RealImage(
            String file) {

        System.out.println(
            "Loading Image...");
    }

    @Override
    public void display() {

        System.out.println(
            "Displaying Image");
    }
}

-------------------------------------------------

class ImageProxy
implements Image {

    private RealImage image;

    private String file;

    public ImageProxy(
            String file) {

        this.file = file;
    }

    @Override
    public void display() {

        if(image == null) {

            image =
                new RealImage(file);
        }

        image.display();
    }
}

EXAMPLE 5 - CACHING PROXY
=================================================

SCENARIO

Expensive database queries should be
cached.

-------------------------------------------------
IMPLEMENTATION MAPPING
-------------------------------------------------

Subject

ProductService

---------------------------------

Real Subject

DatabaseProductService

---------------------------------

Proxy

CachedProductService

-------------------------------------------------
JAVA IMPLEMENTATION
-------------------------------------------------

interface ProductService {

    String getProduct(
            int id);
}

-------------------------------------------------

class DatabaseProductService
implements ProductService {

    @Override
    public String getProduct(
            int id) {

        System.out.println(
            "Fetching From DB");

        return "Laptop";
    }
}

-------------------------------------------------

class CachedProductService
implements ProductService {

    private ProductService service =
            new DatabaseProductService();

    private String cache;

    @Override
    public String getProduct(
            int id) {

        if(cache == null) {

            cache =
                service.getProduct(id);
        }

        return cache;
    }
}

=================================================
COMMON TEMPLATE
=================================================

interface Subject {

    void request();
}

-------------------------------------------------

class RealSubject
implements Subject {

    @Override
    public void request() {

        System.out.println(
            "Real Work");
    }
}

-------------------------------------------------

class Proxy
implements Subject {

    private RealSubject subject =
            new RealSubject();

    @Override
    public void request() {

        System.out.println(
            "Access Check");

        subject.request();
    }
}

WHEN TO USE
=================================================

Use Proxy When:

✔ Access Must Be Controlled

✔ Security Is Required

✔ Lazy Loading Needed

✔ Caching Needed

✔ Remote Calls Exist

Bank Account

Image Loading

Spring AOP

Database Caching

API Gateway

=================================================
WHEN NOT TO USE
=================================================

Simple Direct Access.

Example:

User user = new User();

No Proxy Needed.
