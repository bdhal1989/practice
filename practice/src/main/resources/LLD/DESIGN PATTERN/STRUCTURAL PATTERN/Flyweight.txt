📘 FLYWEIGHT PATTERN - COMPLETE NOTES
=================================================

CATEGORY

Structural Design Pattern

=================================================
DEFINITION
=================================================

Flyweight Pattern is a Structural Design Pattern
used to minimize memory usage by sharing
common objects instead of creating duplicate
objects.

Simple Rule:

Flyweight = Share Objects

OR

Flyweight = Reuse Common Data

=================================================
WHY DO WE NEED IT?
=================================================

Suppose a game contains:

100,000 Soldiers

Every Soldier has:

✔ Gun Type = AK47

✔ Health = 100

✔ Uniform = Army

✔ Armor = Level 5

Only position changes.

-------------------------------------------------

WITHOUT FLYWEIGHT

100,000 Objects

Each stores:

Gun

Uniform

Armor

Health

Position

-------------------------------------------------

Memory Waste

-------------------------------------------------

WITH FLYWEIGHT

Store common data once.

Store changing data separately.

Result:

Huge Memory Savings

=================================================

=================================================
📘 FLYWEIGHT PATTERN
📘 INTRINSIC vs EXTRINSIC STATE
=================================================

The most important concept in Flyweight Pattern
is separating data into:

1. Intrinsic State

2. Extrinsic State

=================================================
📌 INTRINSIC STATE
=================================================

Definition

Intrinsic State is the data that is:

✔ Common

✔ Shared

✔ Reusable

✔ Stored inside Flyweight

✔ Independent of Client

✔ Does not change frequently

-------------------------------------------------

Simple Rule

Can this data be shared
between multiple objects?

YES

→ Intrinsic State

=================================================
📌 EXTRINSIC STATE
=================================================

Definition

Extrinsic State is the data that is:

✔ Unique

✔ Not Shared

✔ Supplied by Client

✔ Changes Frequently

✔ Stored Outside Flyweight

-------------------------------------------------

Simple Rule

Is this data unique for every object?

YES

JAVA IMPLEMENTATION

interface Soldier {

    void display(
            int x,
            int y);
}

-------------------------------------------------

class ArmySoldier
implements Soldier {

    private String gun =
            "AK47";

    private String uniform =
            "Army";

    @Override
    public void display(
            int x,
            int y) {

        System.out.println(
            gun + " "
            + uniform
            + " Position: "
            + x + "," + y);
    }
}

-------------------------------------------------

class SoldierFactory {

    private static
    final Map<String,Soldier>
            cache =
            new HashMap<>();

    public static Soldier
    getSoldier() {

        return cache.computeIfAbsent(
            "ARMY",
            k -> new ArmySoldier()
        );
    }
}

-------------------------------------------------

USAGE

Soldier soldier =
        SoldierFactory
        .getSoldier();

soldier.display(10,20);

COMPONENTS OF FLYWEIGHT
=================================================

1. Flyweight

Shared Object

---------------------------------

2. Concrete Flyweight

Actual Shared Instance

---------------------------------

3. Flyweight Factory

Creates and Reuses Objects

---------------------------------

4. Client

Provides Extrinsic State

=================================================
COMMON TEMPLATE
=================================================

interface Flyweight {

    void operation(
            String extrinsicState);
}

-------------------------------------------------

class ConcreteFlyweight
implements Flyweight {

    private String
            intrinsicState;

    public ConcreteFlyweight(
            String state) {

        this.intrinsicState =
                state;
    }

    @Override
    public void operation(
            String extrinsicState) {

        System.out.println(
            intrinsicState
            + extrinsicState);
    }
}

-------------------------------------------------

class FlyweightFactory {

    private Map<String,
                Flyweight>
                cache =
                new HashMap<>();

    public Flyweight
    getFlyweight(
            String key) {

        return cache.computeIfAbsent(
            key,
            k -> new ConcreteFlyweight(
                    k)
        );
    }
}

=================================================
INTERVIEW ANSWER
=================================================

Flyweight Pattern is a Structural Design
Pattern used to reduce memory consumption
by sharing common parts of object state
among multiple objects. It separates
intrinsic state from extrinsic state and
reuses shared objects through a factory.
